Detailed Description

Serializes and deserializes filter configurations.

Enables saving filter sets as JSON files for team sharing and reusability across sessions.

File Format: filters.json (v1.0)

{
"version": "1.0",
"timestamp": "2026-07-30T10:00:00Z",
"filters": [
{"name": "ERROR", "target": "level", "pattern": "ERROR", "enabled": true}
]
}
