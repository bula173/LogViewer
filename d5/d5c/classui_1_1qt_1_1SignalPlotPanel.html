Detailed Description

Signal value plot panel.

Plots the numeric/signal fields selected in the Signal Browser dock. Call SetSelectedSignals() whenever the selection changes; the chart updates immediately. Refresh() is also called lazily by MainWindow when the tab first becomes visible.
