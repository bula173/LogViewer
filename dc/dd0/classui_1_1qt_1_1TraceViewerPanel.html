Detailed Description

Correlation / trace viewer panel.

Groups visible events by the value of a user-selected field (e.g. requestId, sessionId, traceId). Each unique value becomes a row showing aggregate statistics: event count, error count, duration, and first/last seen timestamps. Double-clicking a row filters the events view to that correlation group.

Refreshes automatically via a modelReset connection wired up in MainWindow.
