Detailed Description

Scenario builder panel.

A scenario is a named, ordered collection of log events assembled by the analyst. Events can be added from the Events table (via button or right-click context menu), reordered, and removed. The whole scenario can be exported as plain text, a Markdown table, or JSON Lines — with a field selector dialog to control which event items appear in the output.

Multiple independent scenarios are supported via the combo box selector. Scenarios persist in QSettings across sessions.
