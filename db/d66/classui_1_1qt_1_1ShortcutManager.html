◆ Register()

void ui::qt::ShortcutManager::Register ( const std::string &  id,
const QString &  category,
const QString &  label,
QAction *  action 
)

Registers action under id, applying any saved override.

action's current shortcut (set by the caller before this call) is treated as the default to reset back to. Calling this again with an id that's already registered updates the entry in place (the action pointer is refreshed and its shortcut is left as-is).
