Detailed Description

Sequence diagram panel.

On Refresh(), runs ActorDiscoverer::Discover on a background thread (QtConcurrent) so the UI stays responsive. Once discovery completes the exchange pattern is stored and RenderDiagram() draws the swimlane. Each arrow is clickable (double-click) to navigate to the source event.

Navigation: scroll bars / mouse wheel scroll, drag pans, Ctrl(Cmd)+wheel, trackpad pinch, the toolbar buttons and Ctrl++ / Ctrl+- / Ctrl+0 zoom. A freshly discovered diagram opens fit to width (never enlarged past 100%); changing the message limit or aliases keeps the current zoom.
