Detailed Description

Loads and indexes evlog template files keyed by (facility, event_type).

Template files use the evlog native format:

facility LOG_USER (or numeric, e.g. 8) event_type 0x00000001 (or decimal) description "Login event" attributes { int uid; char hostname[64]; } format "uid=%uid% host=%hostname%"

Multiple templates may appear in one file, separated by "---". Keywords may also appear with percent-sign delimiters (facility% etc.). Lines starting with '#' or '//' are treated as comments.
