Detailed Description

Helper class encapsulating file operations for MainWindow.

Delegates file I/O operations from MainWindow, reducing its complexity. Manages:

  • File loading with auto-detection or explicit parser selection
  • Session save/load
  • Recent files list
  • DBC/EVLOG template loading
  • File drop handling

Maintains state for file operations and reports back to MainWindow via callbacks and signal-like patterns.

Thread-safe: File operations happen on worker threads; main thread is notified via Qt signals connected in MainWindow.
