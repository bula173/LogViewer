Detailed Description

Helper class encapsulating export and reporting operations for MainWindow.

Delegates export/reporting operations from MainWindow, reducing its complexity. Manages:

  • CSV export
  • JSON export
  • XML export
  • Report generation

Coordinates with ExportManager for actual export operations.
