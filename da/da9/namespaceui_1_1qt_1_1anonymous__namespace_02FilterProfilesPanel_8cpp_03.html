Parses a JSON array of profile entries, rejecting entries with an empty name or a name already present in existingNames.

Shared by LoadFromFile() (existingNames starts empty — dedup only within the file) and HandleImport() (existingNames pre-seeded with the panel's current profile names, so imported profiles that collide are reported back to the caller instead of silently dropped).

Parameters
jParsed JSON value; must be an array to yield any results.
existingNamesNames already taken; updated with each accepted name.
[out]parseErrorsCount of entries that failed to parse as a profile.
[out]rejectedNamesNames skipped due to being empty or a duplicate.
Returns
Successfully parsed, uniquely-named profiles, in file order.
