Detailed Description

Unified search bar for global event search and filtering.

Provides:

  • Type-ahead search across all event fields
  • Live match counter
  • Recent searches history
  • Filter presets for quick access
  • Keyboard shortcuts (Ctrl+F)

The search bar integrates with EventsTableView to navigate and filter matching events, and can save searches for quick re-use.
