Detailed Description

Quick filters offered by the events table context menu: "show only" / "exclude" a cell value and the "conversation" of two actors are built on the column filters (composable, shown by the header funnel, cleared by "Clear All Column Filters"); the time window narrows the upstream filter (see EventsTableView::ShowTimeWindow).
