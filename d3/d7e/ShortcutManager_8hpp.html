Detailed Description

Central registry of user-customizable keyboard shortcuts.

Menu-building code (MainWindow::SetupMenus()) calls Register() right after creating each QAction that carries an application shortcut. The manager applies any previously-saved custom shortcut immediately, and later lets ShortcutsDialog list, edit, and reset shortcuts through GetAll() / SetShortcut() / ResetToDefault().

Overrides are persisted as <appdata>/keybindings.json, a flat map of shortcut id to key sequence string. Only entries that differ from their default are stored.
