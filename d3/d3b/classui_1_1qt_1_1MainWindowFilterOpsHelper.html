Detailed Description

Helper class encapsulating filter and search operations for MainWindow.

Delegates filter/search operations from MainWindow, reducing its complexity. Manages:

  • Filter application and coordination
  • Search orchestration
  • Filter status updates
  • Extended filter handling

Maintains reference to FilterManager for state management.
