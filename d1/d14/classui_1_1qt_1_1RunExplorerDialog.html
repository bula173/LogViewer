Detailed Description

Run Explorer: the tests of one results folder (one safeAPI merged log per test), with verdict, duration, entry count and failure message.

A non-modal dialog: it stays open next to the main window while logs are opened from it. The folder is scanned on a worker thread (analyzer::ScanResultsFolder through QtConcurrent) with a progress bar and a Cancel button. Rows can be sorted by any column, filtered by verdict, and failures grouped by their normalised message.

Activating a test row emits OpenTestRequested(); "Open with Previous Test" emits OpenWithPreviousRequested() with the test that ran just before it.
