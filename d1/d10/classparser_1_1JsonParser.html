Detailed Description

Parses JSON log files in two formats:

Array — a single JSON array of objects at the top level. [ {"ts": "...", "level": "INFO", "msg": "..."}, ... ]

NDJSON — one JSON object per line (newline-delimited JSON / JSONL). {"ts": "...", "level": "INFO", "msg": "..."} {"ts": "...", "level": "WARN", "msg": "..."}

The format is detected automatically: the parser reads the first non-whitespace character; '[' means array mode, '{' means NDJSON mode.

Nested objects and arrays are flattened using dot-notation keys: { "ctx": { "user": "alice" } } → key "ctx.user" = "alice" { "tags": ["a","b"] } → key "tags.0" = "a", "tags.1" = "b"
