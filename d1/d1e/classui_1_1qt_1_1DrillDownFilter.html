Detailed Description

A panel's temporary "drill down" filter (timeline bucket, trace) set on top of whatever filter the rest of the application had set.

It remembers that previous filter, so Restore() brings it back instead of clearing every filter, and the events the panel showed before, so the panel can keep showing them while its own filter is active.
