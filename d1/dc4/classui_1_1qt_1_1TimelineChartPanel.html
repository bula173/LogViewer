Detailed Description

Interactive event-timeline panel.

Displays a stacked bar chart of visible events distributed over time, colour-coded by log level. Clicking a bar narrows the events view to the events in that time bucket. A Clear Selection button removes the bucket filter and restores the previous visible set.

Refreshes automatically via a modelReset connection wired up in MainWindow.
