Detailed Description

Read/write tree panel showing the CAN message/signal structure from a loaded DBC file. Checkboxes let the user select which signals to plot; checking a frame checks or unchecks all its signals.

Lives in its own dock widget tabbed alongside the main Filters dock. Call SetDatabase() whenever a new DBC file is loaded. Emits SignalSelectionChanged() whenever the checked set changes.
