Detailed Description

Manages activity badges on QTabWidget tabs.

Shows a red dot (●) on tabs when they contain updated data. Auto-clears when user switches to that tab.

Usage: auto badgeManager = std::make_unique<TabBadgeManager>(tabWidget); badgeManager->SetBadge(0, "new"); // Show badge on tab 0 badgeManager->ClearBadge(0); // Hide badge on tab 0
