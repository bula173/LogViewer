Helper: Run inference on a prompt using the Gemma model Returns pair<output_text, error_message> - if error is empty, output is valid

Static helper: Run inference on a prompt using the Gemma model Returns pair<output_text, error_message> - if error is empty, output is valid

NOTE: This is a stub implementation. The actual inference loop requires:

  • llama_tokenize(model, prompt, add_bos, special)
  • llama_decode(ctx, batch) for context evaluation
  • llama_sample_* functions for token selection
  • llama_token_to_piece(model, token, buf, buf_size) for decoding The exact API depends on the llama.cpp version used.
