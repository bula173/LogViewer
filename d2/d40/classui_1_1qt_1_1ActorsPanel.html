Detailed Description

Panel showing aggregate statistics per "actor" in the visible event set.

An actor is any field value (e.g. user, IP, process ID) that can be used to identify who performed an action. The panel organises actors by their ActorDefinition, showing hierarchical data with counts, types, and timestamps.

Clicking a checkbox on a row filters the events view to show only events from the selected actors. Multiple actors can be selected.

Refreshes automatically via a modelReset connection wired up in MainWindow.
