Detailed Description

Scans an EventsContainer and discovers actor/exchange patterns without any hard-coded field names — purely by keyword scoring and cardinality.

Works on every log format: JSON microservices (service/target), DLT (ecuid/appid), CAN-bus (channel), XML traces (sender/receiver), etc.
