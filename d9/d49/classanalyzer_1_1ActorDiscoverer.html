Detailed Description

Scans an EventsContainer and discovers every plausible actor/exchange pattern without hard-coded field names.

Detected patterns (in decreasing confidence order): Pair — two fields: senderField + receiverField DirectionField — one actor field + one direction-value field SenderOnly — only a sender-type field; receiver = self ReceiverOnly — only a receiver-type field; sender = self

Works on every log format: JSON microservices, DLT (ecuid/appid), CAN-bus, XML traces, syslog, custom formats.
